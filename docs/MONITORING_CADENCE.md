# 实际监测周期

以部署systemd/code为准，配置文件存在不代表服务当前运行，状态另查systemctl与runtime证据。

| 链路 | 实际设计周期 | 限制 |
|---|---|---|
| Paper socket/订单回调 | 事件到达即处理；主循环每1秒检查 | 无网络/券商响应保证 |
| API heartbeat | 每5秒reqCurrentTime；上游已连接且10秒无reply则判缺失 | 重连有既有退避，不保证10秒内恢复 |
| 持仓/订单/成交完整回读 | 每30秒；dirty等条件可提前 | UNKNOWN/non-idempotent不自动重放 |
| 策略只读评估 | 每5秒 | 不等于获准执行 |
| 行情恢复检查 | 每5秒 | 新鲜度/会话/业务权限分开 |
| Telegram outbox | 有队列约每1秒；空/失败通常5秒等待 | HTTP不确定不重发 |
| 云外心跳 | 每60秒；period60+grace60 | 判Down约120秒后，传输与调度另计 |
| 云端状态/独立回读 | 已配置5分钟timer | 应核对是否启用，不制造额外owner |
| 官方SEC/Fed/BLS情报 | 2分钟+0–20秒随机 | BLS本次403，新增持久退避：403默认1小时，429尊重Retry-After；不是实时全文新闻 |
| IBKR历史新闻 | 15分钟+0–20秒 | 每symbol/provider有界，未验收全量streaming，不擅自提高到触发pacing的频率 |
| 秘书云端收消息 | 5秒长轮询+约0.5秒间隔 | 受网络/audience验证耗时影响；模型不阻塞控制路径 |
| 自主研究 | 每6小时新槽；新指令/新情报任务另排 | 24模型任务/日、每任务最多3轮；可按用户方向调整，不是美元账单上限 |
| 本机秘书资源 | 每5分钟 | 仅观测本进程FD/RSS/CPU/线程/子进程 |
| 数据库页面 | 按需快照 | 不是后台实时扫描 |
| 每日备份 | 03:30UTC+最多5分钟随机延迟 | 当前柏林04:30–04:35；逐库一致、不跨库原子；异地未验收 |
