# Licensing

OpenWorkspace source code is intended to be released under the MIT License.

External projects such as Sunshine, Moonlight, BetterDisplay, and Apple Sidecar are not vendored, copied, or forked by this repository. They must be installed and licensed separately according to their own terms.

Before adding a dependency:

1. Confirm the license permits the intended use.
2. Document the package, version, URL, and license.
3. Prefer documented integration points over source copying.
